# Art direction from this game's brief

Read user references as separate inputs: subject fidelity, visual treatment, layout, typography, animation or mood. If a screenshot concerns layout only, do not copy its art style or assets automatically.

Write a compact visual direction covering:

- **Feeling and audience:** what the player should feel, with concrete composition choices.
- **Visual language:** medium, shapes, level of detail, perspective and consistent scale.
- **Colour and type:** the supplied palette/brand rules, readable body text and a suitable display voice.
- **Scene and UI:** focal points, important objects, control/dialogue space and small-screen composition.
- **Motion and audio:** actions that need feedback, transitions and user controls.
- **Sources:** supplied assets, licences, verified facts and deliberate fictional interpretation.

Use code-drawn assets when that fits the requested medium and delivery constraints. Use image/audio-generation tools only when appropriate, available and within the request; follow their actual tool instructions. Do not claim a visual was generated by a particular service without its record. Style references do not grant permission to redistribute source imagery, logos or game art.

## Reusable art prompt

```text
Create a coherent visual direction for [game name], a [genre] game for [audience].
The repeated action is [core loop], and the intended feeling is [tone].
Use [supplied references] specifically for [style/layout/subject/typography].
Keep [required brand/character details] and the selected [palette/medium].
Define consistent scale, shapes, perspective, lettering and motion across scenes.
Keep the main play information visible and place controls/dialogue to suit the
requested devices. Preserve the game's rules during an art-only revision.
Explain how the proposed visuals serve the actual game. Label generated,
licensed, supplied and code-drawn assets accurately.
```

This prompt is a reusable template. Do not carry the Italia Uno café's blue/cream palette, handwriting, menu or shop imagery into a new brief unless the user chooses them.
