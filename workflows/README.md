# Team Snapper — workflow hub

**[Zhiang Wang / Team Snapper](https://github.com/z48gdcngbf-jpg) · same repository, reusable for new projects.**

## Start here for a specified new game

Use **[Custom Game Builder](custom-game-builder/README.md)** to make a game from another person's brief. Copy that folder alone, or use its [master prompt](custom-game-builder/PROMPT.md), [requirements form](custom-game-builder/INTAKE.md) and [Codex skill](custom-game-builder/SKILL.md).

The workflow covers requirements, mechanics, art, implementation, meaningful checks and source handoff. It does not require the Italia Uno game, its assets or its accounts. The preparation script organises the assignment; a coding assistant executes the build.

## Choose only the modules needed

| Module | Purpose | Status / dependency |
| --- | --- | --- |
| [Custom Game Builder](custom-game-builder/README.md) | A specified game across themes/genres | Portable workflow, skill and workspace preparer; no game runtime dependency. |
| [Gemini creative workflow](gemini-creative-track/README.md) | Document the actual Italia Uno drafting/review conversations | Project case evidence, not proof of new-game implementation. |
| [Project mailbox](email-setup/README.md) | Owner-assisted mailbox preparation when needed | Optional procedure; no account created automatically. |
| [Order receipt email](order-email/README.md) | Plan customer/project copies for an order-based experience | Optional planned integration with an offline case preview; no live sending. |
| [Instagram publishing](instagram-publishing/README.md) | Review, queue, publish and verify authorised content | Optional operator workflow; its actual state/configuration governs use. |

For a simple puzzle or story game, start with the builder and leave external modules off. For another business, use its own facts, identity, references and menu rather than inheriting the café case.
