# 新媒体品牌宣传工作流

Italia Uno 的网站用于让顾客了解店铺体验；`workflows/instagram-publishing/` 用于把已审核的店铺内容安全地安排、发布并核验。两者都在这个仓库内维护，但社媒的账户会话、素材、证据与发布账本只保留在本地。

```text
店铺事实与授权素材 → 编辑审核 → 本地发布队列 → 授权浏览器操作
          ↑                                      ↓
          └───── 实际帖子链接与复核证据 ←──────────┘
```

## 每周内容节奏

1. 从真实店铺信息和已获授权的照片中选题：本周菜单、制作过程、空间故事或活动提醒。
2. 核对事实、图片权利、语言和无障碍替代文本；不要从演示游戏内的虚构价格推导真实商业信息。
3. 由店主审核文案和图片，将单图清单放入本地 `inbox/`，并在确认后标记 `ready: true`。
4. 在约定时间执行发布模块的一次受限循环。每天默认上限为一帖。
5. 重新打开真实的 Instagram 帖子，保存 permalink 和核验结果；不确定则停止并人工核对。
6. 每周复盘实际发布内容、互动和下一周素材缺口。互动数据或回复私信需要另行授权，不属于此工作流的默认范围。

## 运行边界

- 发布必须使用店主授权的 Instagram 账号，并在点击 Share 前再次确认。
- 工作流默认暂停；开启发布是每次运营决定，不是安装后的默认行为。
- 不保存密码、Cookie、令牌或浏览器会话；不提交 `config.json`、账本、证据或真实媒体。
- 仅在发布成功页面与重新打开的帖子都已核对后记录为 `PUBLISHED`。

详细命令和恢复步骤见 [Instagram 发布模块](../workflows/instagram-publishing/README.md)。
